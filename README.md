# 🖼️ ComfyView

**Rust 기반 고성능 AI 이미지 브라우저 & 프롬프트 워크숍 — ComfyUI / A1111 사용자를 위한 데스크톱 도구**

ComfyView는 수만 장의 생성 이미지를 지연 없이 탐색·검색·정리하고, 프롬프트 메타데이터를 분석해 나만의 **와일드카드**로 압축하도록 설계된 Tauri 기반 데스크톱 앱입니다. PC에서 정리하다가 침대에서 휴대폰으로 이어서 분류할 수 있는 **모바일 피드(Comfy Reels)** 도 내장되어 있습니다.

> ⚠️ **고지**
> - 이 프로젝트의 코드는 대부분 바이브코딩으로 작성되었으며, 내부 알고리즘·구동 방식 등 핵심 아키텍처는 제작자가 설계했습니다.
> - 의도치 않은 취약점이 있을 수 있으며 그 책임은 사용자에게 있습니다. 제보된 취약점은 비정기적으로 유지보수됩니다.
> - 메타데이터(프롬프트 등) 추출은 제작자의 ComfyUI 워크플로에 맞춰 설계되어, 다른 워크플로에서의 동작은 보장하지 않습니다.

## 📦 설치 및 실행

**사전 준비:** [Node.js](https://nodejs.org/) 와 [Rust](https://rustup.rs/) 가 설치되어 있어야 합니다.

| 작업 | Windows | 직접 실행 |
|---|---|---|
| 개발 모드 실행 | 루트의 `run.bat` 실행 | `npm install` 후 `npm run tauri dev` |
| 설치 파일 빌드(`.msi` 등) | `build.bat` 실행 | `npm run tauri build` |

`run.bat`은 의존성 설치와 개발 서버 구동을 자동으로 처리합니다. 첫 실행 시 Rust 컴파일로 수 분이 걸릴 수 있습니다.

## 🚀 빠른 시작

1. **Open Folder**(헤더 좌측)로 이미지 폴더를 엽니다. 하위 폴더까지 보려면 **Recursive**를 켭니다.
2. 폴더를 처음 열면 백그라운드에서 메타데이터 인덱싱이 시작됩니다(진행 상황은 하단 푸터에 표시).
3. `←`/`→`로 이미지를 넘기고, `K`로 보관(`_Keep`), `Delete`로 휴지통(`_Trash`)으로 분류합니다. 실수하면 `Ctrl+Z`.
4. 대량 정리는 `B`(Batch) 그리드 모드에서 빠르게 처리합니다.
5. 마음에 드는 이미지들을 **Workshop**으로 보내 와일드카드를 만들거나, **Settings → Mobile**을 켜고 휴대폰으로 이어서 분류합니다.

## 🧭 화면 구성

- **헤더(상단)**: 폴더 열기 / 최근 폴더 드롭다운 / Recursive 토글 / 보기 모드 전환(Single·Batch·Peaking) / 도구(Workshop·Classifier) / 컨텍스트 액션(Random, Move NSFW, Keep, Trash) / 설정(⚙️).
- **사이드바(좌측)**: 검색창과 필터(모델·샘플러), 태그 자동완성. 폭 조절 가능.
- **메인 뷰(중앙)**: 현재 이미지 또는 썸네일 그리드. 줌/팬 지원.
- **인스펙터(우측)**: 현재 이미지의 프롬프트·네거티브·모델·샘플러·시드 등 메타데이터, 유사도 검색, X 공유.
- **푸터(하단)**: 현재 위치, 총 장수, 인덱싱 진행률.

## 🖥️ 보기 모드 (Single · Batch · Peaking)

헤더의 세그먼트 컨트롤 또는 단축키로 전환합니다. 모드를 바꿔도 현재 이미지에 대한 포커스는 유지됩니다.

- **Single** — 한 장을 크게 보며 메타데이터를 확인. 줌/팬 지원.
- **Batch (`B`)** — 가상 스크롤 썸네일 그리드. `Space`로 다중 선택 후 일괄 Keep/Trash/이동. 수천 장을 리드미컬하게 정리할 때 사용.
- **Peaking (`P`)** — 좌측 썸네일 그리드 + 우측 고해상도 뷰어를 동시에 표시. 메타데이터에 방해받지 않고 빠르게 Keep/Trash 분류하는 데 최적화. 그리드에서 이미지를 클릭하면 우측 뷰어가 즉시 갱신되며, 선택(체크) 상태는 유지됩니다.

## 📂 탐색 · 인덱싱 · 실시간 갱신

- **멀티스레드 스캐닝**: Rust `Rayon`으로 이미지와 메타데이터를 병렬 인덱싱하고 `SQLite`에 저장합니다.
- **스프레드 인덱싱**: 수만 장 폴더를 열어도 앱이 멈추지 않습니다. **현재 보고 있는 이미지를 기준으로 양방향으로 퍼져나가며** 가까운 이미지부터 우선 인덱싱합니다.
- **실시간 청크 동기화**: 50장 단위로 즉시 DB에 반영되어, 인덱싱 중에도 프롬프트·검색 결과가 점진적으로 채워집니다.
- **폴더 실시간 감시**: 보고 있는 폴더에 파일이 추가/삭제되면 목록이 자동 갱신됩니다(현재 Recursive/정렬 설정을 따름).
- **최근 폴더**: Open Folder 옆 드롭다운에서 최근 연 폴더로 빠르게 이동합니다.

## 🔎 검색 · 유사도 검색

- **고급 검색**(사이드바): 프롬프트 키워드 + 모델/샘플러 필터를 조합해 즉시 검색. `/`로 검색창에 포커스. **인증 폴더 전체 검색** 옵션을 켜면 현재 폴더를 넘어 등록된 인증 폴더까지 검색합니다.
- **유사도 검색**(인스펙터): 현재 이미지의 태그를 기준으로 비슷한 이미지를 찾습니다. 비교할 태그 개수를 조절할 수 있습니다.
- 검색 결과 보기 중 폴더가 갱신되어도 검색 상태는 유지됩니다.

## 🗂️ 파일 분류 (Keep / Trash / Undo / 이동)

비파괴적 분류 — 영구 삭제 대신 폴더로 이동시키므로 언제든 복구할 수 있습니다.

- **Keep (`K`)**: 원본 경로 하위 `_Keep` 폴더로 이동.
- **Trash (`Delete`)**: `_Trash`로 이동. `_Trash` 안에서 다시 Trash하면 영구 삭제됩니다.
- **Undo (`Ctrl+Z`)**: 최근 이동 작업을 되돌립니다(최대 50회).
- **폴더로 이동 / 검색 결과 이동**: 선택 또는 검색 결과 전체를 지정한 이름의 하위 폴더로 이동.
- **Auto-Classify**: 현재 폴더의 하위 폴더 이름과 이미지의 **파일명 또는 프롬프트**가 일치하면 자동으로 그 폴더로 이동시킵니다. (※ 아래 *Tag Classifier* 도구와는 다른 기능입니다.)

## 🔞 NSFW 분류

특정 NSFW 태그가 포함된 이미지를 한 번에 `nsfw` 하위 폴더로 모읍니다.

- 헤더의 **Move NSFW** 버튼 → 현재 폴더(Recursive면 하위까지)를 스캔해, **양성 프롬프트 또는 파일명**이 설정된 NSFW 키워드와 매칭되는 이미지를 `nsfw` 폴더로 이동합니다.
- 매칭은 **단어 경계 + 복수형** 기준입니다: `sex`는 `sex`/`sexes`에 매칭되지만 `sexy`/`unisex`에는 매칭되지 않고, `nipple`은 `nipples`도 잡습니다. **네거티브 프롬프트는 의도적으로 제외**합니다(네거티브에 넣은 `nude`는 오히려 SFW를 의미하므로).
- 어떤 태그를 NSFW로 볼지는 **Settings → Content Filter (NSFW)** 에서 자유롭게 편집합니다. 이 목록은 모바일 **SFW 모드**와도 공유됩니다.

## 🪄 도구: Wildcard Workshop

수많은 이미지의 프롬프트를 분석해 최적화된 와일드카드 소스(`{tagA|tagB|tagC}`)를 생성하는 엔진입니다. 이미지(폴더/뷰어에서 가져오기)와 텍스트 프롬프트를 함께 입력할 수 있습니다.

- **Jaccard 유사도 분석**: 프롬프트 간 거리를 계산해 비슷한 결과물을 지능적으로 그룹화합니다.
- **병합 모드**
  - **Simple Mode**: 빈도가 높은 공통 태그를 추출하고 나머지를 선택지(`{A|B}`)로 결합.
  - **Mix Mode**: 여러 프롬프트를 재귀적으로 분석해 계층적 와일드카드를 생성.
- **Universal Base**: 모든 프롬프트에서 100% 공통인 핵심 성분을 먼저 분리해 골격을 유지.
- **Preserve Order 모드**: 병합/정렬 없이 입력 순서를 그대로 유지해 결과를 만듭니다.
- **Cleaning Base (공통 태그 빼기)**: 기준 이미지/태그를 지정해 모든 결과에서 공통 군더더기를 제거.
- **태그 정제 필터**: 단어 수 제한, 포함/제외 필터, 중복 제거. **Refine Tags** 창에서 현재 후보 태그를 빈도순으로 보며 체크 한 번으로 제외할 수 있습니다.
- **확장(Expansion) 미리보기 & 저장**: 생성한 패턴이 실제로 어떻게 치환되는지 확인하고 `.txt`로 저장.
- **Pipeline 모드**: 위 과정을 정형화된 파이프라인으로 실행해 결과 파일을 저장.

> 참고: 프롬프트를 태그로 분해할 때 `<lora:...>` 같은 LoRA/임베딩 토큰은 쉼표가 없어 실제 태그에 붙어 있어도 별도 토큰으로 분리되므로, 마지막 태그가 LoRA와 함께 통째로 제거되는 문제가 없습니다.

## 🏷️ 도구: Tag Classifier

프롬프트의 **태그 자체를 분류·정규화**하는 워크스테이션입니다(폴더 이동이 아니라 텍스트 가공).

- **Subset(분류군)**: 키워드/제외 키워드로 정의한 카테고리. 각 줄의 태그가 어느 분류군에 속하는지 색으로 표시됩니다.
- **Word Group(단어 묶음)**: 여러 표기를 하나의 대표 태그로 병합/정규화.
- **Flow Result(실시간 미리보기)**: 현재 줄을 백엔드 분류 로직으로 즉시 분류해 보여줍니다(컴파일 결과와 동일한 로직).
- **Single / Bulk / Library 뷰**: 한 줄 편집, 대량 소스 입력, 프리셋/라이브러리 관리.
- **프리셋**: 자주 쓰는 Subset·Word Group 구성을 저장/불러오기.

## ✂️ 도구: Batch Crop

LoRA 학습·썸네일용으로 여러 이미지를 같은 좌표로 잘라내는 작업을 크게 단축합니다.

- **스마트 스냅 가이드**: 이미지 경계나 다른 크롭 영역에 자석처럼 붙어 정밀 정렬.
- **다중 영역 동시 조작**: 여러 크롭 박스를 동시에 선택해 이동·크기 조절.
- **그리드 / 비율 프리셋**: 1:1·16:9 등 비율 고정, 2x2·3x3 일괄 그리드 생성.
- **시각 보조**: 박스마다 3분할 가이드라인과 실시간 해상도(WxH) 표시.
- **단축키**: `Mouse Drag`(영역 생성), `Shift+Drag`(축/비율 고정), `Alt+Drag`(스냅 무시), `Ctrl+C/V`(크기 복사·붙여넣기), `Delete/Backspace`(영역 삭제).

## 🐦 Twitter(X) 공유

인스펙터의 X 버튼 또는 `T` 단축키로 현재 이미지를 공유합니다. 두 가지 방식을 지원합니다:

- **클립보드 + 브라우저** (API 키 없이): 이미지를 클립보드에 복사하고, 미리 채워진 글과 함께 X 작성 페이지를 엽니다. 브라우저에서 `Ctrl+V`로 이미지를 붙여넣으면 됩니다.
- **API 직접 업로드** (키 입력 시): 설정에 API 키를 넣으면 바로 업로드합니다.

> 🔐 API 키는 평문이 아니라 **OS 키체인(Windows 자격 증명 관리자)** 에 안전하게 저장됩니다.
> 게시 문구 템플릿(`{phrases}` 치환)과 자동 이미지 복사 여부도 설정에서 조정합니다.

## ⚙️ 설정

헤더의 ⚙️ 아이콘에서:

- **Performance** — 이미지 캐시 범위(앞/뒤로 미리 캐시할 장수).
- **Content Filter (NSFW)** — NSFW 키워드 목록 편집(뷰어 Move NSFW + 모바일 SFW 공유). 입력 후 입력란 밖을 클릭하면 적용됩니다.
- **Mobile Connectivity** — 서버 활성화, 포트, 이 PC로 제한, 인증 폴더, 접속 URL.
- **Keyboard Shortcuts** — 단축키 재지정.
- **Twitter (X)** — API 키(키체인 저장), 게시 템플릿, 자동 이미지 복사.
- **Database Management** — 인증 폴더 재인덱싱 / 전체 DB 초기화·재구축(검색이 어긋나거나 느릴 때).

## 📱 모바일 가이드 (Comfy Reels)

PC 앞이 아니어도 휴대폰으로 대량 이미지를 빠르게 감상·분류하고, ComfyUI 생성 결과를 실시간으로 볼 수 있습니다.

### 1) 서버 켜기 & 접속
1. ⚙️ **Settings → Mobile Connectivity** 에서 **Enable Server** 활성화.
2. **Restrict to this PC**(이 PC로 제한)가 **꺼져** 있어야 휴대폰에서 접속됩니다.
3. 표시되는 **Access URL**(`http://192.168.x.x:4882`)을 휴대폰 브라우저에 입력.

### 2) 인증 폴더 (Authorized Folders)
- 설정의 **Authorized Folders** 옆 `+`로 자주 쓰는 루트 폴더를 등록하면, 데스크톱에서 열어주지 않아도 휴대폰에서 그 폴더와 하위를 항상 탐색할 수 있습니다(등록 시 백그라운드 인덱싱).

### 3) 피드 조작
- **상하 스크롤**: 릴스 스타일로 한 장씩 스냅되며 넘김.
- **분류**: 좌우 **스와이프**(왼쪽 🗑️ Trash / 오른쪽 ⭐ Keep) 또는 우측 액션 버튼(**Keep / Skip / Trash**). 분류 직후 잠시 **Undo** 가능.
- **Skip(보류)**: 그냥 다음으로 넘기면 보류 처리.
- **더블탭/핀치 줌**: 이미지를 자세히 보기.
- **위로 스크롤로 이전 이미지 보기**: 특정 위치에서 시작(Resume)해도, 위로 스크롤하면 그 이전 이미지까지 모두 볼 수 있습니다.
- **피드 끝에서 자동 갱신**: 끝에 도달하면 폴더를 재확인해 새로 생긴 이미지를 이어 붙입니다.
- **이어하기 / 점프**: 폴더별 마지막 위치를 저장(**Resume**)하고, 헤더 중앙 인덱스를 터치해 원하는 번호로 점프.
- **Side**: 헤더 **SIDE** 버튼으로 분류 버튼 위치(좌/우) 전환.

### 4) LIVE (실시간 생성 피드)
- 헤더 **LIVE** 토글을 켜면, **지금 보고 있는 폴더**에 새 이미지가 추가될 때 피드 끝에 즉시 붙고, **최신을 보고 있을 때는 포커스가 새 이미지로 따라갑니다**. 뒤로 스크롤해 예전 이미지를 보는 중이면 가로채지 않습니다.
- ComfyUI 출력 폴더가 바뀌면 휴대폰에서 그 폴더로 이동만 하면 됩니다 — 피드가 현재 폴더를 따라 감시합니다.

### 5) SFW 모드
- 헤더 **SFW** 토글을 켜면 설정의 NSFW 키워드에 해당하는 이미지를 피드에서 숨깁니다.

### 6) 주소표시줄 숨기기 (전체화면)
- 피드를 **Start / Resume** 하면 자동으로 전체화면으로 전환되어 브라우저 주소표시줄이 사라집니다(안드로이드 크롬 기준).
- iOS Safari는 전체화면 API가 없으므로, **홈 화면에 추가**해 실행하면 브라우저 크롬 없이 standalone으로 열립니다.
